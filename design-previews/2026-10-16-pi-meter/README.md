# Pi Meter · 480×480 方向样图

> 历史设计原型：以下状态与交互说明保留当时记录，不代表当前固件。最新操作规则见[项目 README](../../README.md)，最新界面渲染见[docs/images](../../docs/images/README.md)。

本目录仅用于选视觉方向，不是固件，也不是实时账单。选择方向只记录偏好，不授权刷机或开始实现。

- A 黑底精密仪表（推荐）：左对齐无衬线大金额，纯黑底。
- B 暖纸数字账单：衬线、居中金额与横向明细；浅底在 AMOLED 上亮屏面积更大。
- C 终端双读数：等宽、上下两层费用与 token 读数。
- D Pi 品牌色：非对称布局，以小色块和文字颜色区分指标。

打开 `index.html` 比较；每个 `a.svg`–`d.svg` 和 `a.png`–`d.png` 均为 480×480。
`overview.png` 为四图总览。HTML 内嵌所有 SVG，可离线看样图；选择回传需要预览服务，离线时请在对话回复选择。

所有方向使用同一组示例：10 月 16 日、$0.79、3.16M tokens、输入 258.8K、输出 24.2K、缓存读取 2.88M、34 次请求、18 秒前更新。数值仅供排版比较，不代表此刻实际统计；总量和细项有显示舍入。`USD · RECORDED` 是日志记录的美元金额/折算值，不是供应商最终账单。

标志来自 Pi README 引用的 https://pi.dev/logo-auto.svg ，保留原始三色路径。页面未使用在线字体或第三方脚本；浏览器实际字体为 Avenir Next / Georgia / Menlo，固件需另行确认可用字库。
