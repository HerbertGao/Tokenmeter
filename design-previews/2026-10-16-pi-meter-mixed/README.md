# Pi Meter：A 布局 × D 品牌色

> 历史设计原型：以下状态与交互说明保留当时记录，不代表当前固件。最新操作规则见[项目 README](../../README.md)，最新界面渲染见[docs/images](../../docs/images/README.md)。

本轮依据用户明确选择合并 A 的左对齐布局与 D 的品牌色。状态仍是**设计预览，等待用户反馈**，不构成 daemon／固件实现或刷机授权。

新版预览：**http://127.0.0.1:8767/**。前两版 8765 / 8766 保持原样。

## 本轮改动

- 首页沿用 A 的位置、层级和三列输入／输出／缓存读取，不采用 D 的错位布局。
- 费用珊瑚色、输入与缓存蓝色、输出金色，总 token 白色；保留小 Pi logo。
- 第二页不再设置 Provider 汇总标签，也不单按 model 跨 provider 合并。每一项明确表示一个 provider/model 身份；provider/ 与 model 分两行显示，兼顾字号与费用列宽。
- 明细按费用降序、每页两条，示例共四项、两页。固定页码、HOME / PREV / NEXT；首末页相应禁用 PREV / NEXT，不循环翻页。
- 上滑前进、下滑返回；支持触摸与鼠标拖动，设备区域聚焦时可用上下方向键。首页上滑进入明细，第一张明细下滑回首页。
- 使用离散分页，不做自由滚动、惯性或过场动画。网页手势是原型，不是已经实现的硬件触摸支持。

这替代前版“跨 Provider 合并同名 model”的设计建议。只采用 provider/model 的身份形式，不宣称复刻 Pi 界面的实际排版。

## 点阵与字体

继续使用旧项目 `assets/DejaVuSansMono.ttf` 字体源，固定 16 / 20 / 24 / 32 / 48 / 96 px，字形透明度量化为 16 级。SVG 内嵌字形 PNG，显示尺寸等于 PNG 原始像素，不依赖本机浏览器字体。单页 PNG 由 Ego 浏览器 SVG → Image.decode → 原尺寸 Canvas 导出。

这不是已转换的 LVGL 字库，也不是硬件截图。字形边界保持 x ≥ 28、y ≥ 20、right ≤ 452、bottom ≤ 454。长 provider 与 model 分别限定列宽、固定字号、中间省略；网页辅助文本保留完整身份，实机如何查看全名未定。

## 验证

- 生成器检查三个 SVG 的 XML、字形边界、费用降序、provider/model 唯一性、同名模型跨 provider 分开，以及费用／token／记录数合计。
- 原尺寸 PNG 价格／内容区有效像素检查通过；已目视检查总览。图片尺寸、内嵌字图原始像素尺寸、PNG 签名及透明度级数另作检查。
- 1200px 视口样机 480×480，无横向溢出；390px 视口样机 354×354，无横向溢出，屏内按钮点击高度至少 44 CSS px。
- 桌面真实按钮、上一页／下一页／返回首页、首末页边界、上下方向键、鼠标纵向拖动通过；横向或不足阈值的拖动不翻页。
- 移动仿真的 CDP 原生触摸上滑／下滑通过，并验证明细 1 → 明细 2 → 明细 1 → 首页。Ego 的一次移动模式 click 回执超时，但页面实际已切至目标；检查当前页面后继续验证，没有强制点击或重复提交。
